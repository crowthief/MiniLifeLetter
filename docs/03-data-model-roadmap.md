# مدل داده و نقشه راه

## ۱. جدول‌ها (SQLite)

### entries
| ستون | نوع | توضیح |
|---|---|---|
| id | TEXT (UUID) | کلید اصلی |
| title | TEXT | اختیاری |
| body | TEXT | محتوا |
| format | TEXT | `rich` یا `markdown` |
| entry_date | TEXT | تاریخ میلادی `YYYY-MM-DD` |
| created_at | INTEGER | زمان ثبت |
| updated_at | INTEGER | آخرین ویرایش |
| deleted_at | INTEGER | برای سطل زباله، پیش‌فرض خالی |

### tags
| ستون | نوع |
|---|---|
| id | TEXT |
| name | TEXT (یکتا) |

### entry_tags
`entry_id`، `tag_id`

### attachments
| ستون | نوع |
|---|---|
| id | TEXT |
| entry_id | TEXT |
| mime | TEXT |
| data | BLOB (رمزنگاری‌شده) |

### settings
`key`، `value` (تم، فونت، زبان، تقویم، قفل خودکار، ساعت یادآور)

### Full-text
جدول `entries_fts` (FTS5) برای جستجوی متن.

> تاریخ در دیتابیس همیشه میلادیه و تبدیل به شمسی فقط در رابط انجام می‌شه.

## ۲. نقشه راه

### مرحله ۱: هسته
- راه‌اندازی Electron + React + TypeScript.
- دیتابیس رمزنگاری‌شده، رمز اصلی، کلید بازیابی.
- ساخت، ویرایش و حذف خاطره با ادیتور متن غنی.
- ذخیره خودکار.

### مرحله ۲: سازماندهی
- تقویم شمسی/میلادی، برچسب‌ها، جستجو.
- حالت Markdown، پیوست عکس.
- سطل زباله.

### مرحله ۳: تجربه
- «در چنین روزی»، آمار و streak.
- تم، فونت، حالت تمرکز.
- قفل خودکار، یادآور روزانه.

### مرحله ۴: خروجی
- پشتیبان‌گیری و بازیابی.
- خروجی PDF.
- ساخت نصب‌کننده برای هر پلتفرم.

## ۳. تصمیم‌های نهایی
- نام اپ: MiniLifeLetter.
- حال‌وهوا حذف شد.
- فونت‌های پیش‌فرض: وزیرمتن و ساحل (ایران‌سنس بعداً، اگر فایلش در دسترس باشد).
- سبک ظاهری: مینیمال و آرام، رنگ‌های ملایم و فضای خالی زیاد.
